# تطبيق جوال لتأجير العاملات + موقع أدمن

هذا المشروع يحتوي على:
- **تطبيق عميل بتصميم جوال** على المسار `/client`.
- شاشات تعريف داخل التطبيق بنمط onboarding (التالي/تخطي) مع عدة صفحات وصور مثل: **رؤيتنا** و **مميزاتنا**.
- **موقع أدمن** على المسار `/admin` (وأيضاً `/office` للتوافق) لإدارة العملاء والحجوزات.
- قاعدة بيانات محلية في `data/db.json` للعملاء والعاملات والحجوزات.

## المزايا
- الدخول كزائر واستعراض العاملات.
- إنشاء حساب/تسجيل دخول عند الرغبة في الحجز.
- حجز بالساعة (تاريخ + وقت بداية + عدد ساعات).
- لوحة الأدمن لعرض العملاء المسجلين والحجوزات وتحديث حالة الحجز.

## التشغيل
```bash
npm start
```
ثم افتح:
- `http://localhost:3000/client`
- `http://localhost:3000/admin`
